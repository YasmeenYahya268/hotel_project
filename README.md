# Hotel Management System

A C++ console application for managing hotel rooms and customer bookings.

## Features
- View all rooms and available rooms
- Book a room and cancel booking
- Search for guest and show all bookings
- Calculate booking cost and total revenue
- Show occupancy rate and longest stay guest
- Sort rooms by price and filter by room type

## How to run
Open `HotelManagementSystem.cbp` in Code::Blocks
